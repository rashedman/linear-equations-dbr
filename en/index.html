5. Core Concepts: Replacement Set vs. Solution Set

ConceptSimple DefinitionExample (2x + 7 = 3)
Linear Equation An algebraic equality where the variable has power 1 (e.g., ax + b = c, a ≠ 0). 2x + 7 = 3 (1st degree in x)
Replacement Set The allowed number universe you may choose solutions from (N, Z, Q, or a given set). Specified in the question (N or Z)
Solution Set (S.S.) Values from the replacement set that make both sides equal. Algebraic root x = -2:
• In Z: S.S. = {-2}
• In N: S.S. = ∅ (since -2 ∉ N)

Interactive Flashcards: Avoid the 4 Common Traps (Click to Flip)

Trap 1 (E1): Subtraction Reversal
❓ Does "subtract 8 from 3x" mean 8 - 3x? (Click to check)
❌ False! Rule: whatever comes after "from" goes first, so it is written 3x - 8.
Trap 2 (E2): Ignoring Replacement Set
❓ You solved x = -2 in N; should you write {-2}? (Click to check)
❌ False! N = {0, 1, 2, ...} has no negatives, so the solution set in N is ∅.
Trap 3 (E3): Sign & Inverse Error
❓ In 2x + 7 = 3, do we add 3 + 7? (Click to check)
❌ False! Use the inverse operation by subtracting 7 from both sides: 2x = 3 - 7 = -4.
Trap 4 (E4): Incomplete Distribution
❓ Does 2(x - 3) equal 2x - 3? (Click to check)
❌ Classic Trap! Multiply 2 by BOTH terms: 2x - 6 (or divide both sides by 2 first).

Worked Examples (Gradual Mastery)

Example 1: Word Translation
"When 15 is subtracted from twice a number, the result is 12."
• Let the number = x, twice the number = 2x.
• What follows "from" comes first: 2x - 15 = 12
Example 2: Replacement Set (N vs Z)
Find the solution set of 2x + 7 = 3 in N and in Z:
• 2x = 3 - 7 = -4 ⇒ x = -2
• In Z: {-2} | In N: ∅ (because -2 ∉ N)
Example 3: Rational Solution (Q)
Solve in Q: 3x + 11 = 9
• Subtract 11 from both sides: 3x = 9 - 11 = -2
• Divide by 3: x = -2/3 ∈ Q
Example 4: Distributive Property
Solve: 2(x - 3) = 8
• Distribute: 2x - 6 = 8 ⇒ 2x = 14 ⇒ x = 7
• Or divide by 2 first: x - 3 = 4 ⇒ x = 7
